# Python Loops and Functions 🐍

## 📌 About the Project

This repository contains **Python Assignment 3**, which focuses on learning and implementing `while` loops, `for` loops, control statements, and functions in Python.

The assignment includes three beginner-friendly Python programs that demonstrate basic programming concepts through practical examples.

## 🎯 Objectives

- Understand the use of `while` and `for` loops.
- Learn control statements such as `break`, `continue`, and `else`.
- Generate multiplication tables using `range()`.
- Define and call functions in Python.
- Practice taking user input and displaying output.

## 📂 Programs Included

### 1. Number Guessing Game 🎮

**File:** `number_guessing_game.py`

A simple game in which the computer generates a random number between 1 and 10, and the user tries to guess it within three valid attempts.

**Concepts used:**
- `while` loop
- `if`, `elif`, and `else`
- `break` and `continue`
- `random.randint()`

### 2. Multiplication Table Generator ✖️

**File:** `multiplication_table.py`

Generates the multiplication table from 1 to 10 for a number entered by the user.

**Concepts used:**
- `for` loop
- `range()`
- User input
- Arithmetic operators

### 3. BMI Calculator ⚖️

**File:** `bmi_calculator.py`

Calculates Body Mass Index (BMI) using the user's weight in kilograms and height in meters.

**Formula:**

BMI = Weight (kg) / Height (m)²

**Concepts used:**
- Functions using `def`
- Parameters and return values
- `float()` input conversion
- Formatted output

- Python 3 installed on your computer.

## 🚀 How to Run the Programs

**Step 1:** Clone this repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

**Step 2:** Open the project folder in VS Code.

**Step 3:** Open the terminal using **Terminal → New Terminal**.

**Step 4:** Run each program separately.

Number Guessing Game:

```bash
python number_guessing_game.py
```

Multiplication Table:

```bash
python multiplication_table.py
```

BMI Calculator:

```bash
python bmi_calculator.py
```

On Windows, you can use `py` instead of `python` if required.
